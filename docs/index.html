🚀 快速开始

三步在本地启动融合平台。

# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 API Key（至少一个 LLM 提供商）
cp config/apikey.env.example config/apikey.env

# 3. 启动应用
streamlit run app.py

预置角色：admin（系统管理员）· doctor（医生）· nurse（护士）
登录凭据存于本地 config/auth.yaml（已加入 .gitignore，不入库）

⚠️ 本平台输出由人工智能生成，仅供研究与参考，不构成专业医疗建议。实际诊疗请咨询执业医师。
